# Remote Job AI Agent — Version 2

Working local web app with a Python/FastAPI backend and live integrations with Himalayas and Jobicy.

## Run on Windows
1. Install Python 3.11+.
2. Open Command Prompt in this folder.
3. `python -m venv .venv`
4. `.venv\\Scripts\\activate`
5. `pip install -r requirements.txt`
6. `uvicorn app:app --reload`
7. Open `http://127.0.0.1:8000`

## Included
- Live job search
- Europe filtering
- €50K target signal
- Product Owner/ERP-oriented matching
- Original application links
- Responsive dashboard

This version does not auto-submit applications. Submission will be approval-based and only through permitted integrations/workflows.

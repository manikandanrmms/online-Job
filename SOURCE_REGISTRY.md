# Global Remote Job AI Agent v3.1 — Source Registry

Verified: 2026-08-30

## Aggregated sources enabled in app.py

- Himalayas — JSON API
- Jobicy — JSON API
- We Work Remotely — RSS
- Remote OK — JSON feed
- Arbeitnow — public API

## External-search sources shown in the frontend

- LinkedIn
- Naukri
- FlexJobs
- Wellfound
- Remote.co
- Indeed
- Glassdoor
- Working Nomads

External-search platforms are opened directly rather than scraped without authorization.

## Features

- Worldwide/Anywhere default
- North America, Europe, Asia-Pacific, Latin America, Africa and Middle East filters
- Country filtering
- Worldwide / region-locked classification
- Timezone restriction detection
- Remote-First / Remote-Friendly / Remote-OK classification
- USD salary normalization
- Minimum and maximum salary filters
- Salary disclosed / unknown / negotiable modes
- Deduplication
- Relevance, date, salary and company sorting
- Pagination
- Saved jobs in browser local storage
- Source failure isolation
- FX endpoint with cached live rates and fallback rates
- Source verification metadata

## Important

Free source access does not guarantee that every employer's application process is free. Always verify eligibility and application requirements on the original job page.
